# Evidencija proizvoda

Web aplikacija za evidenciju proizvoda, količine i rokova trajanja.

## Live Demo

https://evidencija-proizvoda.onrender.com/

## Funkcionalnosti
- Dodavanje proizvoda
- Prikaz svih proizvoda
- Pretraga proizvoda
- Izmjena proizvoda
- Brisanje proizvoda
- Upozorenje za rok trajanja proizvoda

## Tehnologije
- Python
- Flask
- SQLite
- HTML
- CSS

## Pokretanje aplikacije
Za pokretanje aplikacije potrebno je imati instaliran Python.
1. Preuzeti projekat sa GitHub-a.
2. Otvoriti folder projekta.
3. Instalirati Flask.
4. Pokrenuti aplikaciju komandom `python app.py`.
5. Otvoriti adresu koju Flask prikaže u terminalu.
